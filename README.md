# AISkillet Cookbook

First-party, original skills for [AISkillet](https://aiskillet.com) — the marketplace for AI skills, plugins, agents, and MCP servers.

Each skill is a folder under [`skills/`](skills/) following the Agent Skills convention (`SKILL.md` with YAML frontmatter + Markdown body). These are curated, opinionated, and written from scratch to set the quality bar for the catalog.

## Skills

| Skill | What it covers |
|---|---|
| [`api-design`](skills/api-design/SKILL.md) | Consistent, evolvable HTTP/JSON APIs |
| [`code-review`](skills/code-review/SKILL.md) | Reviewing a diff for correctness, security, and clarity |
| [`writing-quality-code`](skills/writing-quality-code/SKILL.md) | Writing better code and proving it with tests |

## The quality bar

Every skill: explicit "When to Activate", actionable over academic, opinionated defaults, original + concrete examples, scannable, self-contained. See the platform's `architecture/ARCHITECTURE.md` §14.
