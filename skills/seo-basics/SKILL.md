# SEO Basics

SEO isn't tricks — it's making genuinely useful pages that search engines can find, understand, and trust. Nail intent, structure, and speed; skip the snake oil.

## When to Activate
- Publishing content or building marketing/landing pages
- A site that isn't getting organic traffic
- Auditing pages for search visibility

## Start with intent
Write for a real query and its **search intent** (informational / navigational / transactional). Match the page to what a searcher actually wants — the best "ranking factor" is being the most useful result for that intent.

## On-page essentials
- **Title tag:** unique, ~50–60 chars, primary keyword near the front, compelling (it's the clickable headline in results).
- **Meta description:** ~150 chars — doesn't rank directly, but drives click-through. Write it like ad copy.
- **One `<h1>`** per page stating the topic; logical `h2/h3` structure.
- **Headings + first paragraph** address the query directly; use natural language, not keyword stuffing.
- **Descriptive URLs** (`/blog/api-design-guide`), **internal links** with meaningful anchor text, **alt text** on images.

## Technical + trust
- **Performance:** fast Core Web Vitals (LCP/CLS/INP) — speed and stability affect ranking and UX.
- **Mobile-first & crawlable:** responsive, no render-blocking of content, clean `robots.txt` + XML **sitemap**.
- **Structured data** (schema.org) for rich results where relevant.
- **Canonical tags** to avoid duplicate-content splits.
- **E-E-A-T:** demonstrate experience/expertise; earn links by being genuinely worth citing.

## Avoid
- Keyword stuffing, thin/duplicate pages, buying links, cloaking — all backfire.

## Checklist
- [ ] Page matches a real query's search intent
- [ ] Unique title (keyword front) + compelling meta description
- [ ] One h1, logical headings, descriptive URL, internal links, alt text
- [ ] Fast Core Web Vitals; mobile-friendly; sitemap + canonical
- [ ] Genuinely useful, original content (no stuffing/thin pages)
